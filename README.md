# Juju Finanças 🌸

App pessoal de finanças (Argentina + Brasil) que abre em tela cheia no iPhone, com ícone próprio.
Os dados ficam no Firebase Realtime Database da dona, protegidos por e-mail e senha.

## Arquivos
- `index.html` — o app inteiro
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — nome e ícone na tela inicial
- `sw.js` — deixa o app abrir rápido

## Publicar (GitHub Pages)
1. Envie estes arquivos para um repositório público no GitHub.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e toque em **Save**.
3. O app fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Instalar no iPhone
Abra o endereço no navegador, toque em **Compartilhar → Adicionar à Tela de Início**.
Na primeira vez, o app mostra o passo a passo do Firebase e pede para criar a conta.
